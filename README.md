# Smart Task Dashboard

🔗 Live Demo: https://notio-three.vercel.app/  
📂 GitHub Repo: https://github.com/AMIRUL1104/SmartTasKDashboard  

## 🚀 Overview
Smart Task Dashboard is a Notion-style task management web application that helps users create, manage, and track tasks efficiently with a clean and responsive UI.

## ✨ Features
- Add, edit, and delete tasks
- Task status tracking (Pending, In Progress, Done)
- Priority-based filtering (Low, Medium, High)
- Category-based organization
- Real-time search functionality
- Instant UI updates using React state
- Data persistence with LocalStorage
- Fully responsive (mobile-first design)

## 🛠️ Tech Stack
- React.js
- JavaScript (ES6+)
- HTML5
- CSS3 / Tailwind CSS
- LocalStorage API

## 🧠 Concepts Used
- Component-based architecture
- useState & useEffect hooks
- Conditional rendering
- List rendering
- Event handling
- Data persistence

## 📱 UI Focus
- Clean and minimal dashboard UI
- Mobile-friendly layout
- Fast and interactive user experience
